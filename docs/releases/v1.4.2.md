# iMic 1.4.2

## 修复

- **Qoder、Cursor 等 Electron 编辑器中实时文字错位、结果后残留多余文字**：1.4.1 的润色扫光为定位输入框会向 Electron 应用请求开放辅助功能树（`AXManualAccessibility`），该开关在应用退出前一直有效。之后再次录音时，iMic 能读到输入框范围，便从键盘兼容模式切换为 AX 范围修订：说话过程中改写中间文字时，先用 AX 选中尾部再替换并放回光标。Qoder、Cursor、VS Code 的 Monaco 输入框与 Claude 等富文本输入框的真实光标与 AX 范围不同步，选区和光标会落到错误位置，部分文字脱离本轮管控，最终残留在结果后面。
  - 现在检测到应用包含 `Electron Framework.framework` 时，一律直接使用键盘兼容模式（与 Codex、Otty 相同），不主动设置 AX 选区，恢复 1.4.0 及之前在这些应用中的输入方式。
  - 扫光仍可使用开放后的辅助功能树定位，只作为视觉提示，不再影响文字写入方式。

## 验证

- 输入范围行为测试（`scripts/test-input.sh`）全部通过，新增 Electron 应用直接选择键盘兼容模式的用例。
- 本版本发布时测试机处于锁屏状态，尚未在 Qoder / Cursor 中完成真实应用复测；问题如仍出现，请附上 `~/Library/Logs/iMic/iMic.log` 中的 `mode=` 相关行反馈。

## 已知边界

- 键盘兼容模式按本轮已投递文字计算退格与追加，无法独立核验目标程序自行改稿或丢弃按键，存在重复或误删的原有风险。
- 扫光开启的辅助功能树不会自动关闭；VS Code 系编辑器检测到辅助功能后可能进入屏幕阅读器优化模式。

本版只修改 Mac 端；iPhone 端与 1.4.1 相同，安装包一并提供以保持版本号一致。

## 下载与安装

- **macOS 13+**：`iMic-1.4.2-macOS-universal.dmg`，支持 Apple Silicon 与 Intel。
- **iOS 17+ / iPhone**：`iMic-1.4.2-iOS-unsigned.ipa`，需要用自己的 Apple ID 或开发团队重新签名安装；不是免签包、TestFlight 或 App Store 分发。
- **校验**：两个安装包与 `SHA256SUMS.txt` 放在同一目录，执行 `shasum -a 256 -c SHA256SUMS.txt`。
- 完整源码对应本 Release 的 `v1.4.2` 标签。
- Mac 公开包为 ad-hoc 签名、未公证；首次打开可能需要在系统设置中允许。

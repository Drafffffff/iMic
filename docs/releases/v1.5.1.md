# VoxChord 1.5.1

## 主要更新

### Mac

- **打开窗口时显示 Dock 图标**：打开主窗口、设置、文本历史、首次设置向导或更新窗口时，VoxChord 会出现在 Dock 和 Cmd-Tab 切换器中，并显示菜单栏；窗口最小化时仍保留。关掉最后一个窗口后回到仅菜单栏图标，不占 Dock 位置。

iPhone 端没有变化，继续使用 1.5.0。

## 下载与安装

- **macOS 13+**：`VoxChord-1.5.1-macOS-universal.dmg`，支持 Apple Silicon 与 Intel，使用 Developer ID 签名并通过 Apple 公证。已安装的 Mac 客户端会通过自动更新收到本版本。
- **iPhone / iOS 17+**：[App Store](https://apps.apple.com/app/id6829771739)。
- **自行签名安装**：`iMic-1.5.1-iOS-unsigned.ipa` 是未签名真机包，需使用自己的 Apple ID 或开发团队重新签名，不能直接点击安装。
- **校验**：安装包与 `SHA256SUMS.txt` 放在同一目录，执行 `shasum -a 256 -c SHA256SUMS.txt`。
- 完整源码对应本 Release 的 `v1.5.1` 标签。

- iOS：源码营销版本同步为 1.5.1，本次不提交 App Store。

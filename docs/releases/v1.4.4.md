# iMic 1.4.4

## 主要更新

### Mac

- **统一百炼，一个 Key 搞定**：没有选过服务来源时，润色一律默认使用百炼；有百炼 Key 时默认开启 AI 润色。首次设置向导的 Key 步骤新增"同时启用 AI 润色（推荐）"，默认勾选。识别模型改为只读显示。DeepSeek 官方 API 和自定义服务仍可在「高级」中选择。
- **设置窗口改为分页**：分为通用、百炼、iPhone、权限、高级五页，取代原来的一列长滚动。开关改了即时生效；Key 和服务地址各自"验证并保存"，不再有底部的全局保存按钮。关闭窗口时如果还有未保存的修改，会先提醒。
- **安静启动**：设置完成后，启动时只出现在菜单栏，不再每次弹出主窗口；可在「通用」中打开"启动时显示主窗口"。
- **登录时启动**：「通用」新增开关，使用系统登录项，默认关闭。
- **主窗口**：已配对、等待连接时，显示已配对的设备，不再以配对码为主角；配对新 iPhone 时再展开配对码。
- **菜单栏**：顶部显示连接状态，可以直接开关 AI 润色、切换转换模式。

### iPhone

- **自动连接已配对的 Mac**：启动、回到前台或断线后，优先连接上次使用的 Mac；它不在线时，约 1.5 秒后自动改连最近用过、在线的其他已配对 Mac。只要已经配对过 Mac，就不会自动连接未配对的电脑。蓝牙后备也同样接受任意已配对的 Mac。
- **音效修复**：修复了多数时候听不到音效的问题。原因是音效借用了录音的音频会话，录音结束后会话被关闭，音效也随之失效。
- **全新 8-bit 音效**：19 个界面音效全部重做，改为实时合成的 8-bit lo-fi 风格。发射（下拉弦松手回车）改为厚重的冲击加呼啸，按力度分三档；松手和识别完成的音效明显区分。设置中新增 SOUND 开关。音效遵守静音开关。
- **待机变暗不再修改系统亮度**：闲置 60 秒后，只在 iMic 窗口上渐变盖一层黑色遮罩；第一次触摸即撤掉，切到后台也会撤掉。系统亮度和自动亮度完全由系统管理，修复了反复待机后屏幕越来越暗的问题。
- **默认显示效果改为 FLOW**：接收时光弧绕环转动，取代原来整圈发亮的 CHARGE。已手动选过效果的不受影响。
- **Bundle ID 改为 `art.malette.imic`**：为了在发布团队下上架 TestFlight。iPhone 会把它当作新 App，需要在新 App 中重新配对 Mac，旧版 App 可以删除。Mac 端不受影响。

建议 Mac 与 iPhone 同时更新至 **1.4.4**。

## 下载与安装

- **macOS 13+**：`iMic-1.4.4-macOS-universal.dmg`，支持 Apple Silicon 与 Intel；Developer ID 签名并已通过 Apple 公证，双击即可打开。
- **iOS 17+ / iPhone**：`iMic-1.4.4-iOS-unsigned.ipa`，需要用自己的 Apple ID 或开发团队重新签名安装；不是免签包，也不是 TestFlight 或 App Store 分发。
- **校验**：两个安装包与 `SHA256SUMS.txt` 放在同一目录，执行 `shasum -a 256 -c SHA256SUMS.txt`。
- 完整源码对应本 Release 的 `v1.4.4` 标签。

## 边界说明

- 从 1.4.3 及更早版本升级的 iPhone 用户，需要在新 App 中输入 Mac 显示的配对码重新配对一次。
- 登录时启动只在从「应用程序」文件夹运行时可用。
- 终端与 Chrome 等的扫光依赖屏幕录制权限做 OCR；扫光只是视觉提示，从不作为写入或修改文字的依据。

# 下一版待同步的改动

已提交、尚未进入任何发布包的改动。下次发版时并入发布说明，然后清空本文件。

## Mac

- **设置向导改为先填 Key 再开权限**（`314747b`）：步骤顺序改为 `01 API KEY → 02 PERMISSIONS`，可能触发"退出并重新打开"的屏幕录制放在最后。向导进度记录在 `setup.inProgressStep`，没点「完成」时重新打开 iMic 会回到原来那一步。修复了开启屏幕录制、重新打开 iMic 后向导被静默跳过的问题：原先能读到 Key（例如 shell 中的 `DASHSCOPE_API_KEY`）且权限已开，就会被当成设置已完成，Key 步骤和"启用 AI 润色"的选择都不会出现。
  - 待真机验证：在未授权过的 Mac 上走一遍"开屏幕录制 → 系统要求重开 → 回到向导第 2 步 → 完成"。

## iPhone

- 新增可恢复的首次引导：介绍双端用法，通过接力、共享或复制把 Mac 下载页送到电脑；解释本地网络授权，再搜索并复用六位码配对。已配对老用户直接进入主页。
- 新增五张交互式手势练习，复用录音横条、弦的弹簧识别及触感音效；练习只修改模拟输入框，不录音、不请求录音权限、不向 Mac 发送内容。设置中的「使用教程」可重新练习或获取 Mac 版。
- READY「开始使用」依次请求麦克风、语音识别权限，拒绝也可进入主页；老用户按住只兜底麦克风，语音识别延后到松手后。练习仅拦截用户内容，握手和心跳继续保活；暂缓搜索时回到前台不会提前弹本地网络权限。

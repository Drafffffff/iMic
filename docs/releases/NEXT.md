# 下一版待同步的改动

- iPhone 默认等待上次成功连接的 Mac，局域网与蓝牙均不再自动跳到其他已配对电脑；设备页支持删除在线或离线配对，删除当前设备需确认，移除后等待手动选择；删除上次成功目标也不会在重启后误恢复更旧设备，本轮正在手选的其他目标继续等待。录音/识别中的删除先取消当前语音并保留本地文字。

- iPhone 修复 VPIO 录音时同一麦克风因会话采样率/声道变化被误判为输入设备变化、取消本轮的问题；按输入端口集合判断设备变化，健康配置通知继续采集，实际引擎停止或格式不可用时共享单次恢复预算重建。MIC TEST 保留会话与采集格式诊断。

- iPhone 从后台返回时刷新 Bonjour 发现并校验加密链路，修复退役发现器回调、恢复交接及等待配对码导致的重连悬挂；手动配对意图在首个 hello 前后均保留，健康语音连接继续使用原传输。

# 下一版待同步的改动

- iOS：修复切到后台再回前台后经常断联、只能划掉 App 重开才恢复的问题。挂起期间失效的连接若先于“回到前台”被处理，原先会丢掉这次前台恢复并沿用挂起前已失效的 Bonjour 发现器；现在会在断线交接完成后补做完整的前台恢复，重连退避也会重建没有结果的发现器。
- Mac：用户可见名称统一为 VoxChord。构建产物与安装位置改为 `VoxChord.app`，DMG 改名为 `VoxChord-<版本>-macOS-universal.dmg`、卷名 `VoxChord <版本>`，局域网与蓝牙广播名改为 `VoxChord · …`。Bundle ID、协议、可执行文件名与支持目录不变；`install-mac.sh` 会备份并替换旧的 `/Applications/iMic.app`。Sparkle 原地更新保留用户现有路径。
- Mac：新增「文本历史」，保存每一轮的原始识别与润色/转换后的文字、时间、目标应用和模式，可搜索、复制、删除；数据只保存在本机。
- Mac：新增「自定义词库」（设置 › 词库，⌘6）。词条只保存在本机，识别时作为百炼即时热词随请求发送（默认权重 4，可按润色模式启用），润色时作为专有名词表保护写法；支持纯文本导入导出。词库被百炼拒绝时自动不带词库重试一次，不丢这段话。iPhone 与协议不变。

# iMic 1.4.1

## 主要更新

- **Mac 润色扫光定位更稳**：
  - AX 行范围给出空矩形的编辑器，改用 WebKit/Chromium 的文本标记接口，从光标向前逐行读取并核对正文。
  - Electron 应用（Claude、ChatGPT、Cursor 等）会先请求开放辅助功能树，不再因为找不到输入框而退回整窗 OCR。
  - 编辑器能给出几何信息时，最终布局优先采用编辑器数据，OCR 只在最后一次尝试时补位。
- **OCR 回退修复**：
  - 行首、行尾少量字识别错误时，下划线不再缩到行中间（截图中「的效果呢。请再」的问题）。
  - 一行内没有剩余字母或数字时贴齐整行边缘，句末标点也被覆盖；整行直接使用识别框，不再依赖 Vision 对中英混排的插值。
  - 两到五个字的短文本在输入框内只接受唯一的完全匹配，Chrome 搜索框等短输入也能定位。
  - 窗口级 OCR 忽略代码编辑器和终端的行号。
  - 最终阶段的尾部核对也区分输入框与整窗，短文本不再退回估算。
- **外接 1x 显示器上的 OCR 错位**：截图请求按 2 倍尺寸，但 ScreenCaptureKit 默认不放大，1x 屏幕上的窗口内容只占画布左上角，所有识别框都映射错位，下划线穿过文字中部、端点落在行中间。现在开启按比例缩放，Retina 与 1x 屏幕一致。
- **其他细节**：行距很紧时抬高上一行的下划线，避免压到下一行文字；输入框超出屏幕时不再绘制；多段文字在编辑器能提供几何时按真实换行标出每段一个端点。
- **iPhone 弹射余烬**：发射时从弦上崩出少量方形余烬，部分先弹起、部分从飞行中的字上脱落，受重力下落，由近白冷却为橙色并闪烁熄灭。总数有上限，减少动态效果时不出现。
- **真实应用自测**：新增 `scripts/test-polish-apps.sh`，在 Chrome、Safari、TextEdit、Zed、Cursor、终端等应用中按不同光标位置输入并截图核对。自测程序与 iMic 同签名、同 Bundle ID，只在自己打开的测试文档中输入，从不按回车；发布包不包含这段代码。

## 真实应用实测

用 `scripts/test-polish-apps.sh` 在本机逐一核对（光标位置：空白、文后、文前、行中、前后空格、短文本、前后换行、段落之间、一行扩到四行、滚动长文、超长单行）：

| 应用 | 定位方式 | 结果 |
| --- | --- | --- |
| TextEdit | AX 行范围 | 11 种情形扫光与收尾端点都与系统光标重合（偏差 0px） |
| Safari（textarea / 富文本） | AX 行范围、文本标记 | 扫光全部 0px；收尾除纯 textarea 的段落之间、滚动两种情形为估算（约 20px）外为 0px |
| 终端（Terminal.app） | AX 行范围 | 0px；超长单行收尾为估算 |
| Chrome（input / textarea / 富文本） | OCR | 常规位置全部命中；外接 1x 屏幕错位已修复 |
| Cursor | 整窗 OCR | 多数位置可用；短文本、段落之间、滚动长文仍会跳过 |
| Zed | 整窗 OCR | 多数位置可用；短文本、段落之间、滚动长文仍会跳过 |

本机未安装 Pages、Word，未测试；iTerm 与 Otty 在运行测试脚本前会弹出确认框，自测未覆盖。

建议 Mac 与 iPhone 同时更新至 **1.4.1**。

## 下载与安装

- **macOS 13+**：`iMic-1.4.1-macOS-universal.dmg`，支持 Apple Silicon 与 Intel。
- **iOS 17+ / iPhone**：`iMic-1.4.1-iOS-unsigned.ipa`，需要用自己的 Apple ID 或开发团队重新签名安装；不是免签包、TestFlight 或 App Store 分发。
- **校验**：两个安装包与 `SHA256SUMS.txt` 放在同一目录，执行 `shasum -a 256 -c SHA256SUMS.txt`。
- 完整源码对应本 Release 的 `v1.4.1` 标签。

## 边界说明

- Chrome 只有在 VoiceOver 等辅助技术开启时才提供文字几何，平时依靠 OCR；需要屏幕录制权限。
- Zed、Cursor 等不公开文本控件或只暴露隐藏输入框的编辑器只能整窗 OCR，短文本、多段落和滚动长文可能不显示扫光（不影响文字输入）。
- 1x 屏幕上字号很小的两三个字可能无法被 OCR 识别，此时不显示扫光。
- Mac 公开包为 ad-hoc 签名、未公证；首次打开可能需要在系统设置中允许。
- 扫光只是视觉提示，从不作为写入或修改文字的依据。

# iMic 1.4.7

## 主要更新

### iPhone

- **固定连接上次使用的 Mac**：默认等待上次成功连接的 Mac，局域网与蓝牙均不再自动跳到其他已配对电脑；临时点选只有认证成功后才会成为下次启动的默认设备。
- **删除配对设备**：设备页可删除在线或离线的已配对 Mac。删除当前设备需确认，移除后等待手动选择；录音或识别中删除会先取消本轮语音并保留本地文字。删除上次成功目标后，重启也不会误连更旧的历史设备。
- **从后台返回后可靠重连**：返回前台时刷新 Bonjour 发现并校验加密链路，修复旧发现器回调、恢复交接及等待配对码导致的重连卡住；手动配对意图在握手前后均保留，健康的语音连接继续使用原链路。
- **修复 VPIO 录音被误取消**：同一麦克风因系统调整采样率或声道而发出路由通知时，不再被误判为输入设备变化而取消本轮；按输入端口集合判断设备变化，引擎实际停止或格式不可用时按单次预算重建。MIC TEST 保留会话与采集格式诊断。

### Mac

- 无功能变化；随版本号同步发布，签名与公证方式不变。

建议 Mac 与 iPhone 同时更新至 **1.4.7**。

## 下载与安装

- **macOS 13+**：`iMic-1.4.7-macOS-universal.dmg`，支持 Apple Silicon 与 Intel，使用 Developer ID 签名并通过 Apple 公证。
- **iPhone / iOS 17+**：可从官网的 TestFlight 链接安装；本版本的上传结果会在发布记录中补充。
- **自行签名安装**：`iMic-1.4.7-iOS-unsigned.ipa` 是未签名真机包，需使用自己的 Apple ID 或开发团队重新签名，不能直接点击安装。
- **校验**：两个安装包与 `SHA256SUMS.txt` 放在同一目录，执行 `shasum -a 256 -c SHA256SUMS.txt`。
- 完整源码对应本 Release 的 `v1.4.7` 标签。

## 边界说明

- 首次安装 Mac 仍需授权辅助功能；屏幕录制仅支持润色扫光等本地视觉提示。
- 实时预览的键盘兼容模式无法独立核验目标程序自行改稿或丢弃按键，可能重复或误删；用户接管或切换应用会停止本轮输入。
- 已配对多台 Mac 时，上次使用的 Mac 离线不会自动切换到其他电脑，需在设备页手动选择。

# VoxChord 1.5.0

## 主要更新

### iPhone

- **切回前台不再断联**：修复切到后台再回来后经常卡在「搜索中」、只能划掉 App 重开才恢复的问题。挂起期间失效的连接若先于「回到前台」被处理，原先会丢掉这次前台恢复，并沿用挂起前已失效的局域网发现器；现在断线交接完成后会补做完整的前台恢复，重连退避也会重建没有结果的发现器。
- **去掉新手引导**：打开 App 直接进入主页。还没配对 Mac 时，主页会显示官网地址 drafffffff.github.io/iMic，点一下即可分享或复制链接到 Mac；使用说明统一放在官网，设置中的「GUIDE」可直接打开。

### Mac

- **文本历史**：保存每一轮的原始识别与润色/转换后的文字、时间、目标应用和模式，可搜索、复制、删除，方便找回没能输入成功的文字。数据只保存在本机。
- **自定义词库**：在「设置 → 词库」添加人名、产品名、技术术语，识别时作为百炼热词提高准确率，润色时保持原有写法；可按润色模式启用，支持纯文本导入导出。词库只保存在本机；百炼拒绝词库时会自动不带词库重试一次，不丢这段话。
- **名称统一为 VoxChord**：App 包、安装位置、DMG 与卷名、局域网和蓝牙广播名都改为 VoxChord。Bundle ID、协议与支持目录不变，辅助功能授权与配对关系保留；自动更新原地替换，保留你现有的安装路径。已上架的 iPhone 1.4.9 也能识别新名称。

### 官网

- 新增**更新日志**页面（中英文）。
- iPhone 版改为从 **App Store** 下载。
- 补充 Mac mini、Mac Studio 没有麦克风时的使用说明。

建议 Mac 与 iPhone 同时更新至 **1.5.0**。

## 下载与安装

- **macOS 13+**：`VoxChord-1.5.0-macOS-universal.dmg`，支持 Apple Silicon 与 Intel，使用 Developer ID 签名并通过 Apple 公证。已安装的 Mac 客户端会通过自动更新收到本版本。
- **iPhone / iOS 17+**：[App Store](https://apps.apple.com/app/id6829771739)；更新上架以 Apple 审核为准。
- **自行签名安装**：`iMic-1.5.0-iOS-unsigned.ipa` 是未签名真机包，需使用自己的 Apple ID 或开发团队重新签名，不能直接点击安装。
- **校验**：安装包与 `SHA256SUMS.txt` 放在同一目录，执行 `shasum -a 256 -c SHA256SUMS.txt`。
- 完整源码对应本 Release 的 `v1.5.0` 标签。

# iMic 1.4.0

## 主要更新

- **iPhone 原生荧光界面**：主界面接入统一 Metal 显示管线，真实 3D 圆环、字形与界面共同合成 HDR 辉光和 CRT 纹理。设置提供清晰、荧光、荧光 CRT 三档；降低外围雾光，强化扫描纹，保留清晰线芯。
- **界面细节**：统一波形四角标签和角点的对齐，细化底部录音条的字阶、字距、分隔线及计时/图标区。润色配置直接放在设置页；系统时间、电量与网络状态继续显示。
- **弦与文字动效**：保留实时频谱、蓄力、接触亮弧、首次过中线发射及字形快门；优化随机字形落点、阅读与附着表现。松手提示仅在下拉达到发射状态时出现，底部不重复显示整组手势说明。
- **清空输入修复**：顶部上拉清空不再仅依赖编辑器的 AXValue 写入。写值不支持或被忽略时，改为核验完整选区后删除，并确认输入框为空；焦点变化、用户接管、只读或不可核验目标会拒绝操作。
- **自动补全干扰修复**：兼容输入路径读不到选区时，不再预先发送一次右方向键，避免意外接受 Codex 等编辑器的占位补全。没有新增 Tab 或跳到整框末尾的操作。
- **待机与录音**：完善环境动画渐停、前台闲置屏幕变暗、触摸恢复和手动亮度接管；优化录音启动、音频资源释放及触感音效。
- **文字转换设置**：两端统一为“润色开关 → 转换模式 → 表达语气 → 输出语言”。支持 Agent 指令、终端命令、文言文、废话文学、翻译腔五种模式，四种语气及中英日韩四种语言；移除强度和“保持原语言”。提示词以保留原意和结构为优先，终端模式只输入、不执行。
- **Mac 润色显示**：包含分级定位、窗口 OCR 回退、背景自适应配色和原文到润色文本的扫光过渡优化。

建议 Mac 与 iPhone 同时更新至 **1.4.0**。

## 下载与安装

- **macOS 13+**：`iMic-1.4.0-macOS-universal.dmg`，支持 Apple Silicon 与 Intel。
- **iOS 17+ / iPhone**：`iMic-1.4.0-iOS-unsigned.ipa`，需要用自己的 Apple ID 或开发团队重新签名安装；不是免签包、TestFlight 或 App Store 分发。
- **校验**：两个安装包与 `SHA256SUMS.txt` 放在同一目录，执行 `shasum -a 256 -c SHA256SUMS.txt`。
- 完整源码对应本 Release 的 `v1.4.0` 标签。

## 边界说明

- Mac 公开包为 ad-hoc 签名、未公证；首次打开可能需要在系统设置中允许。
- 顶部清空要求能读取并核验当前可编辑文本控件，仍不向不透明页面或终端输出区盲发删除。
- 普通自动输入与实时预览的键盘兼容模式继续依据本轮投递记录操作；目标编辑器自行改稿或丢弃按键时，无法独立确认全部正文。用户手动按键、点击或切换应用会冻结本轮自动修订。
- 设置页与可选择的结果正文继续使用原生控件；主界面的 HDR Bloom 不代表所有原生表单均已纹理化。
- 发布包不包含个人设备描述文件、配对令牌、服务 Key 或签名私钥；识别和润色服务需自行配置。

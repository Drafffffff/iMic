# iMic 1.3.0

## 主要更新

- **iPhone 弹射与弦手势**：文字从手指正上方的录音横条顶边出现，按文字量调整视觉字号与数量；采用箭矢高初速、空气阻力、每次独立的轨道扰动和完整姿态快门采样，增强发射速度感。上拉支持渐进收细、分段齿感、更快连删及顶部清空；碰顶后短振、消隐并强力回弹。
- **电脑处理期间锁定拉弦**：Mac 识别、润色、扫光、最终回写及收尾动画全部完成后，才允许手机拉弦。清空操作需 Mac 明确确认，同次触摸只触发一次。
- **Mac 润色扫光**：在原文位置进行 OCR 对齐与逐行扫描，长文滚动时按窗口和滚动视口裁剪可见区域，等待润色和最终投递完成后释放；支持关闭特效。超时、无权限或定位失败时回退正常输入，用户接管会停止本轮自动修改。
- **输入可靠性**：处理 AX 修订结果不确定、选区滞留与迟到回调，避免重放已写入的修订；完善 Codex 等编辑器的键盘兼容路径。
- **前后台恢复**：返回前台清除旧重试退避，使用加密存活检查复用正常连接，失效时立即重建；保留恢复期间新录音的本地缓存。
- **界面与待机**：更新 iPhone 主界面、设备入口和润色设置；前台空闲后逐渐收起环境动效并停止显示回调，后台释放音频资源。

建议 Mac 与 iPhone 同时更新至 **1.3.0**，以使用手势就绪门控和顶部清空。

## 下载与安装

- **macOS 13+**：`iMic-1.3.0-macOS-universal.dmg`，支持 Apple Silicon 与 Intel。
- **iOS 17+ / iPhone**：`iMic-1.3.0-iOS-unsigned.ipa`，需使用自己的 Apple ID 或开发团队重新签名安装；不是免签包、TestFlight 或 App Store 分发。
- **校验**：将两个安装包与 `SHA256SUMS.txt` 放在同一目录，执行 `shasum -a 256 -c SHA256SUMS.txt`。
- 完整源码对应本 Release 的 `v1.3.0` 标签，可在发布页下载源码归档。

## 已知边界

- Mac 公开包使用 ad-hoc 签名，未做 Apple 公证；首次打开可能需要在「系统设置 → 隐私与安全性」中允许。
- 顶部清空仅对当前焦点未变化、AXValue 可写且能核验为空的文本控件执行；无法核验的自定义编辑器或终端会提示失败。
- 键盘兼容模式依据本轮投递记录修改尾部，不能独立核验编辑器自行改稿或丢弃按键；录音期间混合编辑仍可能产生重复文字或误删风险。
- 重连测试使用生产两端代码与本机 TCP 故障代理，涵盖 55 秒静默断链；不将本机数据作为真机 Wi-Fi 或蓝牙的耗时保证。
- 润色扫光需要 macOS 14+ 与屏幕录制权限；图像只在本机内存处理。识别及可选润色仍需自行配置服务凭据。
- 发布包不包含个人描述文件、设备清单、配对令牌或签名私钥。

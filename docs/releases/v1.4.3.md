# iMic 1.4.3

## 主要更新

- **Mac 首次设置向导**：首次打开分两步引导——打开辅助功能（可选屏幕录制），再填入百炼 API Key 并当场验证。授权失效、从磁盘映像运行等情况给出修复步骤；只有百炼 Key 也能使用润色。Key 改存于 `~/Library/Application Support/iMic/credentials.json`（目录 0700、文件 0600），不再改写 `~/.zshrc`。只装命令行工具即可构建 Mac 端。
- **润色扫光**：
  - 写入润色结果时，下划线不再先消失，而是变成变淡的骨架线，沿线循环扫过高光，像网页骨架屏的加载状态；骨架会伸缩到新文字的估算长度，确认排版后新下划线在最终位置逐行画出。
  - Chrome 等依靠 OCR 的输入框改为按截图中真实字迹校准每行：下划线统一贴在字底，行尾准确，不再随标点忽高忽低。
  - 终端（Terminal、Otty 等）对中文只报告一半宽度的位置，端点会落在行中间；现对终端里的中日韩文字改用 OCR。
- **输入安全**：目标为终端（含编辑器内置终端）时，换行与制表符替换为空格，多行润色结果不会逐行执行；所有应用丢弃 ESC 等控制字符；终端命令模式拒绝含制表符的结果。
- **iPhone**：空弹弦时，弦回弹越过基准线不再点亮顶部的清空区，只有手指上拉时才显示。

建议 Mac 与 iPhone 同时更新至 **1.4.3**。

## 下载与安装

- **macOS 13+**：`iMic-1.4.3-macOS-universal.dmg`，支持 Apple Silicon 与 Intel。
- **iOS 17+ / iPhone**：`iMic-1.4.3-iOS-unsigned.ipa`，需要用自己的 Apple ID 或开发团队重新签名安装；不是免签包、TestFlight 或 App Store 分发。
- **校验**：两个安装包与 `SHA256SUMS.txt` 放在同一目录，执行 `shasum -a 256 -c SHA256SUMS.txt`。
- 完整源码对应本 Release 的 `v1.4.3` 标签。

## 边界说明

- Mac 公开包为 ad-hoc 签名、未公证；首次打开可能需要在系统设置中允许。
- 终端与 Chrome 等的扫光依赖屏幕录制权限做 OCR；Zed、Cursor 等默认不折行的编辑器中，长行尾部在窗口外时不显示扫光。
- 扫光只是视觉提示，从不作为写入或修改文字的依据。

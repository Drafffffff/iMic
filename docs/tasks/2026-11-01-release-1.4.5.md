## 4. Sparkle 更新签名密钥（只做一次）

1. `./scripts/fetch-sparkle.sh`。
2. 运行 `build/vendor/Sparkle/bin/generate_keys`。私钥保存在当前用户的登录钥匙串（这是它的默认行为）。如果钥匙串已有 Sparkle 密钥，**不要生成新的**，直接用 `generate_keys -p` 读取已有公钥。
3. 把输出的公钥写入 `mac/sparkle-public-key.txt`（替换占位值）。
4. 导出私钥备份：`build/vendor/Sparkle/bin/generate_keys -x ~/Documents/iMic-Sparkle-Private-Key-BACKUP`，然后 `chmod 600` 该文件。**这个文件绝不能进入仓库、日志、PR 或任何输出**；在最终报告中只写它的路径，并提醒用户把它移到安全的地方（如密码管理器或加密盘）。
5. 如果 `generate_keys` 弹出钥匙串授权对话框导致无法继续，停止并在输出中说明，不要尝试绕过。

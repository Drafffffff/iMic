用户已明确要求：新手引导完成后发布新版本，并更新 TestFlight。

- 版本：**1.4.6**。Mac 构建号 `MAC_BUILD` = **3**；iOS `CURRENT_PROJECT_VERSION` = **5**，`MARKETING_VERSION` = **1.4.6**。
- 包含 `codex/ui-phosphor-wireframe` 最新提交上的全部改动（`docs/releases/NEXT.md` 中记录的内容）。不包含 `codex/ios-quick-mac-switch`。

## 3. Mac 正式版

1. `IMIC_RELEASE_IDENTITY="Developer ID Application: KE CHENG (5H39F98ND4)" IMIC_NOTARY_PROFILE=iMic-5H39F98ND4 ./scripts/package-release.sh`。
2. 核对：DMG 已公证并 staple，`spctl -a -vv` 通过；`site/appcast.xml` 有 1.4.6 条目，`sparkle:version` 为 3，带 EdDSA 签名与长度，1.4.5 条目保留。
3. 提交版本号、发布说明、appcast，推送。
4. `gh release create v1.4.6`（目标为该提交，标题 `iMic 1.4.6`，正文用 `docs/releases/v1.4.6.md`，上传 DMG、未签名 IPA、`SHA256SUMS.txt`，标记 latest）。
5. 下载 Release 中的 DMG，核对 SHA-256 与长度，与 appcast 一致。

## 4. iOS TestFlight

1. 在同一分支：`./scripts/testflight.sh archive-unsigned`，`./scripts/testflight.sh check`。
2. `IMIC_PROFILE_PATH=~/Documents/iMic-Signing/iMic-AppStore.mobileprovision ./scripts/testflight.sh export`，核对 IPA：签名 `Apple Distribution: KE CHENG (5H39F98ND4)`，Bundle ID `art.malette.imic.app`，1.4.6 (5)，`get-task-allow=false`，`beta-reports-active=true`，嵌入描述文件 UUID `30a12efe-…`。描述文件已安装在 Xcode 的描述文件目录。
3. `IMIC_PROFILE_PATH=… ./scripts/testflight.sh upload`，只尝试一次。记录 Apple 返回结果与 Delivery UUID。
4. 认证或网络失败（例如 `-1202` 证书错误）：停止并报告原始错误，不重试其他账号。

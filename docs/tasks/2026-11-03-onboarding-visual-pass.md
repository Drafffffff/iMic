## 2. 设计方向：让引导说 App 自己的 HUD 语言

### 2.1 教学面：复用主页已有的状态区，不另造悬浮文字

主页本来就有一块「状态区」：`VOICE / INPUT` 小标签 + 像素状态字（READY / LISTEN / DONE）+ 下面一行状态说明。**引导就用这块区域教学**：

- 练习每一步，状态字直接显示当前要做的动作，像素字、与 READY 同一位置同一字号：`HOLD`、`RELEASE`、`PULL`（中英文界面都用英文像素字，这是技术标签）。当前步骤的状态字用橙色，与真实使用中「活动状态」的配色一致。
- 状态字下方原本放状态说明的那一行，放这一步的一句中文/英文提示（例如「按住底部横条，说一句话」）。字体、字号、颜色与真实状态说明一致。
- 用户完成动作后，状态字按真实流程切换（例如 LISTEN → DONE），再进入下一步。这样教学和真实使用在视觉上是同一个东西。
- **删除**所有悬浮在弦与横条之间的提示文字。

### 2.2 指向目标：用 HUD 角标，不用压暗遮罩

- 不再整体压暗主页（尤其不要压暗录音横条）。被教学的目标用**四个 HUD 角括号**（和主页刻度/角标同样的细线、同样的象牙白或橙色）框住，轻微呼吸（亮度 60% ↔ 100%，约 1.6 秒一周期）；减少动态效果时静止。
- 其余区域保持原样，最多降低到 70% 亮度，绝不低于这个值；录音横条在任何步骤都保持原本的橙色。
- 手势示意（下拉弦等）沿用真实路径，但用主页的视觉元素：一个小的象牙白方点（像素风，不要圆形手指），带短拖尾，走一遍后消失。

### 2.3 页头：跳过与进度放进 HUD

- 「跳过」和进度放在页头右侧，替换练习模式下的 `PRACTICE ›` 设备入口位置，用与 `SYS 01`、`PRACTICE` 相同的等宽小字 HUD 样式，例如 `GUIDE 01/03 · SKIP`（中文界面：`GUIDE 01/03 · 跳过`，技术部分保持英文像素/等宽字）。点击区域不小于 44pt。
- 不要在页头下方另起一行放「跳过」。

### 2.4 欢迎：不需要单独的欢迎层

- 删除白色「开始」按钮和居中的字标（左上角已经有字标）。
- 欢迎就是主页处于 READY：状态字 `READY`，状态说明一行显示标语「一只手机，接管所有输入。」。
- 主操作就是**真实的录音横条**：横条文字在引导中显示 `HOLD TO START`（像素字，与 HOLD TO SPEAK 同样式），按住即进入第 1 步并直接开始练习，不需要先点一个按钮。
- 「我已经用过 iMic」改为页头 HUD 中的一项小字链接（例如 `GUIDE · 已用过`），或放在横条下方原 `PCM / 16K` 那一行左侧，用同样的等宽小字样式，不要单独居中。

### 2.5 「更多手势」：HUD 面板，不压横条

- 改为与设置页相同语言的面板：1pt 细边框（`Theme` 中的线条色）、无圆角或很小圆角、背景与主页一致；标题用像素/等宽小字 `MORE / GESTURES`。
- 内容是 4 行手势，每行左侧一个像素箭头图形、右侧一句说明（上拨删字、左右移光标、拉到顶清空、上滑取消），右侧小字 `TRY ›`；底部一行 `LATER`。
- 位置在弦的上方区域（状态区下方），**不得遮挡录音横条和弦**。

### 2.6 连接 Mac：同一套 HUD 框架

- 保留真实的设备列表与配对组件，但放进主页同样的框架：顶部同样的字标 + `SYS 01` 页头；去掉系统导航标题。
- 页面标题区用与状态区相同的结构：小标签 `LINK / MAC`，像素状态字 `SCAN`（搜索中）→ `FOUND`（找到）→ `PAIR`（输入配对码），下面一行说明（「在 Mac 上打开 iMic」等）。
- 设备列表用设置页「连接电脑」的行样式与细线分隔，左侧像素电脑图标，选中用橙色像素对勾。
- 搜索中的加载：用像素扫描点（三个方块依次点亮）代替系统菊花。
- 「稍后再连接」用页头 HUD 小字或底部等宽小字，不居中悬浮。
- 下载弹层：用真实的 App 字标资源（`Wordmark`），不要另一种像素字体；分享/复制行用设置页行样式。
- 配对码输入框沿用现有组件，可以接受；但上方说明与下方提示按本文字号规范统一。

### 2.7 第一次真实输入与完成

- 同 2.1：状态字 `READY` + 说明「在 Mac 上点进输入框，按住说话」；麦克风权限说明作为第二行小字放在同一区域。
- 完成：状态字按真实流程显示 `DONE`，说明行显示「完成。以后就这样用。」，约 2 秒后恢复正常状态说明。不要另起悬浮文字。

## 3. 统一规范

- **字体**：像素字只用于技术标签与状态字（HOLD / RELEASE / PULL / SCAN / DONE 等）；页头 HUD 用现有等宽小字；说明文字用系统字体，大小、颜色与主页状态说明一致。
- **颜色**：橙色只用于当前目标、活动状态字与选中项；说明文字象牙白；次要文字用现有 muted 色。**禁止白色实心填充按钮。**
- **对齐**：所有左对齐元素与页头字标左边缘对齐；不使用居中悬浮文字。
- **新增组件最少化**：优先复用 `HomeView`、`InstrumentChrome`、`PhosphorArtwork`、设置页行样式与 `Theme` 中已有的样式和常量；不要为引导新建一套颜色或字体常量。
- **动效**：状态字切换沿用主页现有的状态切换动效；角括号呼吸与方点示意遵守减少动态效果。
- **可访问性**：VoiceOver 读出状态字与说明；角括号目标保留原控件的可访问性标签；动态字体下说明行不截断。

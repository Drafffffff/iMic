# iOS 主界面：Metal 荧光显示管线

替代 [第一版局部荧光材质](2026-10-27-native-phosphor.md)。保留原黑橙界面、字标、像素标签、切角录音条、系统状态栏和原有交互，重新实现主界面的显示输出。

## 显示与输入

主界面的波形、附着文字、弹射文字及界面视觉由同一个 `CAMetalLayer` 输出。底下仍是原来的 SwiftUI 按钮、手势和辅助功能节点；Metal 层不接收触摸、不创建辅助功能节点。不会截取键盘、系统状态栏或其他应用。

`PhosphorArtwork` 是不包含 UIKit 控件和计时器的纯视觉视图。状态或布局变化时，`ImageRenderer` 将它生成到 sRGB 纹理。波形每帧更新时不重复生成界面纹理；录音秒数复用原字形图集单独绘制。原始控件与视觉纹理使用同一组状态、布局锚点和尺寸。

设置页、设备页和可选择的结果正文继续原生显示，以保留输入、选择、滚动和辅助功能。这些页面使用静态 CRT 玻璃层；它们没有接入主界面的 HDR Bloom。波形复看仍使用原来的 Canvas 绘制。不可将这一版描述成整个应用所有页面均已进入同一 HDR 管线。

## 渲染顺序

1. 真实 xyz 圆环、轨道、弦和文字光弧生成实例线段。正交相机投影，使用深度缓冲；只有线芯（覆盖率过半）写入深度，抗锯齿边缘不遮挡相邻线段。线段在 core 与 emission 上都用 max 混合，同一圆环的接缝不会叠亮成串珠。
2. 一次 MRT 绘制产生 `RGBA16Float` 清晰线芯与 HDR emission，深度为 `Depth32Float`。
3. 在文字绘制前更新半分辨率磷光历史：`max(current, previous × exp(-dt / 0.012))`，进入 Bloom 种子时再乘 0.5。原 32ms 寿命下线圈发光约 140ms 才消失，拖动时形成残影。进入页面、尺寸或材质变化、间隔超过 0.2 秒时清空历史。
4. 原字形图集、运动轨迹与居中快门采样写入同一 MRT。文字不进入历史纹理，避免增加第二套残影。图集带 5 级 mipmap，按每个字的屏幕尺寸显式选择 LOD（上限 3.5），缩小、旋转时不碎裂；新页先清零。文字落到圆环后收进一段光弧：光弧由场景按圆环方程逐点采样，屏幕长度约 14pt，琥珀色（拉弦蓄力时升温到近白），外加一层淡橙色光晕；字形本身淡出，发射时再从光弧处恢复。光弧统一使用环线之前的固定深度，不被起伏的相邻圆环逐帧遮挡，各段之间也不互相打孔。每环最多 10 段，被新落点挤出的一段在 0.3 秒内淡出。
5. 发光数据、波形历史和有分区权重的 UI 发光形成 Bloom 种子。满色录音条权重很低，中文说明也限制发光，避免大块橙色雾遮挡界面。
6. 半、四分之一、八分之一分辨率各做一次横向和纵向高斯模糊，合成近、中、远三层光晕。HDR 能量在模糊前不会被 8 位纹理截断。
7. 清晰线芯覆盖 UI；加入 Bloom，再做固定的高光渐近压缩、轻暗角与静态颗粒。扫描纹使用 1.8pt 周期，在高像素密度屏幕上也能辨认；RGB 子像素 mask 按物理像素定位。线芯、字形和 UI 共用屏幕坐标与扫描响应。线芯与字形的扫描深度随亮度降低（`imicAdaptiveResponse`）：橙色线框保留完整纹理，白热文字与光弧填满扫描间隙；Bloom 种子只取扫描的平均能量，不带条纹。
8. 输出 `bgra8Unorm_srgb`，由 Metal 编码一次 sRGB。内部 HDR 用于积累和扩散发光，最终仍为 SDR，不依赖设备 EDR 或自动曝光。

`PhosphorResponse.h` 为线条、字形及兼容显示路径提供共同的扫描与 RGB mask 函数。Shader 为本项目实现，没有把 RetroArch 的显示器预设直接套到手机界面上。

## 真 3D 与原动效

`PhosphorRing` 的两个单位基向量正交，圆环具有真实深度；并非只有一组二维椭圆贴图。正视投影被校准到原 `TorusGeometry.Layout` 的中心、大小、旋转，因此原手势与文字接触落点保持对应。深度按照中心线积分构造，未采用完整的平行输运曲面框架；目前镜头保持正视，不增加旋转手势。

原 `SpectrumStore`、`StringMotionStore`、`WaveformInkStore`、字形密度预算、弹射物理、首次过中线触发输入和快门曝光模型继续使用。文字光弧、蓄力增亮、发射冲击波（从拉弦点沿线圈扩散，出发点不留亮斑）、外围轨道、清空区、录音按压弹簧、顶部信号线均有新显示路径。落点只保留光弧自身的一次闪光；原冲击亮弧与径向火花在 Metal 场景中移除，回退 Canvas 仍保留。

润色状态同样画在线圈上：从松手到 Mac 完成润色与输入，光弧降为半亮，一道扫描带每 1.2 秒从左到右读过线圈；完成并可发射时，一次确认光带扫过，光弧回到全亮并随环境时钟缓慢呼吸，状态字为 `POLISH`，完成后仍为 `DONE`，说明文字提示「下拉松手发射」。上下外围轨道各有一个随环境时钟反向环绕的光点，保留原来的六秒周期与待机渐停。光点现在用短光弧表示：先端最亮，尾端沿运动反方向渐暗、收细；轨道与光弧的远侧亮度降至近侧的 45%，连续变化以表达前后关系。Metal 与 Canvas 兼容路径共用 `PhosphorOrbitLight` 参数；没有提高整体辉光增益。

文字附着方式可在 设置 → DISPLAY → 文字附着 中切换，偏好保存在 `imic.display.attach`：「整环充能」（默认）不画光弧，落点所在圆环整体变暖并向相邻圆环缓慢扩散，落线瞬间整环闪亮一次；「流动光弧」让光弧沿各自圆环按环境时钟缓慢转动，一半顺时针一半逆时针，发射时文字从光弧当前位置弹出；「静止光弧」停在落点。调试时可用启动参数 `-imic.display.attach charge|flow|arc` 直接指定。发射或清空后不再提示「下拉松手发射」，直到下一次录音。调试构建可用 `--ui-preview=flight --debug-flight-status` 预览。录音按压采用解析弹簧，并在重新按压时保持位置和速度连续。

调试构建可使用 `--debug-scene-view=side` 或 `oblique` 检查真实空间结构；这些参数不在 Release 中生效。

## 性能与降级

- 沿用 `SpectrumStore` 唯一显示时钟；渲染器不创建 `CADisplayLink` 或保活计时器。
- 长待机增加独立的[界面休眠遮罩](idle-screen-power.md)：无操作 60 秒后仅使当前 iMic 窗口渐暗，首次触摸恢复，不修改系统亮度，也不为遮罩更新重新唤醒渲染时钟。
- 保留停止操作后 40 秒保持、4 秒渐停、零待机显示回调、触摸唤醒与后台暂停。打开结果页、设置页或切到后台时暂停主界面环境动画。
- 纹理按尺寸复用，实例缓冲使用三个在途槽，字形继续使用原图集和异步光栅化队列。
- 1206 × 2622 像素下，主要 HDR、深度、历史和 Bloom 目标合计约 88 MiB；不包含界面纹理、字形图集、drawable 和驱动开销。
- `PhosphorMetrics` 在 command buffer 完成时记录 GPU 时间，每 240 帧汇报均值、p95 与最大值，跳过首次 12 帧。模拟器数据只作为回归指标，不能当成手机 GPU/功耗结论。
- 设置 → DISPLAY 提供「清晰」「荧光」「荧光 CRT」，默认 CRT，偏好保存在 `imic.display.material`。减少动态效果沿用原降级；降低透明度关闭新 Bloom 和 CRT。
- 辉光收敛：默认增益从 1.25 降至 0.65，后又按使用反馈降至 0.5，中/远层权重从 0.36/0.20 降至 0.25/0.08，状态字 emission 权重从 1.15 降至 0.85。近层权重、清晰线芯、CRT 参数与动画保持原值，优先消除圆环之间的雾状叠光。
- 后续单独加强 CRT 纹理：扫描调制由 0.18 增至 0.28，RGB mask 的非主通道抑制由 4% 增至 6%，保持扫描周期及收弱后的 Bloom 参数。主显示、发光种子与原生玻璃层共用 `imicScanResponse`。
- 「松手弹射想法」只在可用的下拉手势达到发射阈值、仍按住等待松手时出现在顶部说明处；松手或收回阈值内即恢复原状态文案。待机仍提示按住说话，录音仍提示松开发送及上滑取消，底部不重复显示整组弦手势说明。
- Metal 或界面纹理初始化失败时，恢复原 Canvas 波形与原生界面，避免黑屏。

## 验证入口

```bash
./scripts/test-phosphor.sh
./scripts/test-receiver-flight.sh

IMIC_SIM_NAME=<simulator-uuid> \
IMIC_SIM_APP=<Debug-iphonesimulator/iMic.app> \
./scripts/test-ios-standby.sh

cd ios
xcodegen generate
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
xcodebuild -project iMic.xcodeproj -scheme iMic -configuration Debug \
  -destination 'platform=iOS Simulator,id=<simulator-uuid>' \
  CODE_SIGNING_ALLOWED=NO test
```

`tests/Phosphor` 直接编译生产 Metal shader，验证 xyz/投影、Swift/Metal 内存布局、HDR MRT、残影衰减与重置、模糊光晕、清晰模式色彩、CRT 可测调制、按压弹簧连续性。`tests/iOSUI` 检查三档模式切换、原生录音触摸穿透、结果入口和设备页往返。UI 预览没有麦克风采样，录音释放后的丢弃提示用于确认触摸路径；结果页另用 result 预览验证。

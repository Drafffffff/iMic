## 发现

### [P2] ASR 错误回调形成循环引用，每轮识别器及历史正文无法释放

- 位置：[mac/main.swift:710](../../../mac/main.swift:710)、[mac/ASR.swift:320](../../../mac/ASR.swift:320)。
- 证据：`recognizer.onError` 虽弱引用 `self`，但通过 `recognizer.failureCode` 强引用识别器自身，形成 `recognizer → onError → recognizer`。`cancel()` 只清理计时器、音频队列和 transport，未断开回调或清空 `results`、`confirmedText`。
- 触发条件：正常开始一次云识别，随后成功、失败或取消；主调用方将 `asr` 置空仍无法解除循环。
- 后果：每轮泄漏一个识别器及其已识别正文，内存随会话累积，历史文字持续驻留到进程退出。
- 建议修复：将该闭包改为 `[weak self, weak recognizer]`，在回调中解包后读取 `failureCode`。增加成功、失败和取消后识别器弱引用归零的生命周期回归。
- 置信度：高。

### [P2] 自定义 Key 可写出无法读取的凭据文件，后续保存会丢失其他服务凭据

- 位置：[mac/Credentials.swift:44](../../../mac/Credentials.swift:44)、[mac/Credentials.swift:125](../../../mac/Credentials.swift:125)、[mac/Credentials.swift:134](../../../mac/Credentials.swift:134)。
- 证据：自定义服务的 `validToken()` 没有长度上限；`set()` 编码后直接写入，而 `read()` 将超过 `64_000` 字节的文件当成空的 `Stored()`。读取失败与首次不存在文件使用同一返回值。
- 触发条件：已有其他服务 Key，再保存一个由 `64_001` 个 ASCII `A` 组成的自定义 token。它通过当前格式检查，且必然使 JSON 超过读取上限。界面路径还需兼容服务验证通过。
- 后果：刷新或重启后，文件中的所有 Key 均读不到；没有环境变量或 shell 配置兜底时服务失效。随后保存任何较短 Key，会从空字典重写文件，永久删除原有其他 Key。
- 建议修复：限制自定义 token 长度，并在 `CredentialFile.set()` 写入前检查最终编码大小；将“文件不存在”与“超限、损坏、读取失败”区分，后者应报错并保留原文件。
- 置信度：高。

### [P2] 最终识别结果绕过句子连续性检查，缺句仍按成功提交

- 位置：[mac/ASR.swift:281](../../../mac/ASR.swift:281)、[mac/ASR.swift:298](../../../mac/ASR.swift:298)。
- 证据：实时确认阶段通过 `confirmedThrough` 等待连续句子；但收到 `task-finished` 后直接执行 `results.keys.sorted()...joined()`，不再检查缺号，并调用 `onFinal`。
- 触发条件：同一任务收到结束句 `sentence_id=1` 和 `3`，未收到 `2`，随后本地 `end()` 并收到 `task-finished`。现有缺句测试只覆盖第二句最终补齐的情况。
- 后果：第一、三句被直接拼成成功结果并进入润色或自动输入，第二句静默缺失。已有连续性守卫在最终提交时失效。
- 建议修复：最终成功前核验全部已接收结束句均属于连续前缀，例如检查最大句子序号与 `confirmedThrough` 一致；缺号时走明确的异常事件失败路径，保留可复制预览。补充“缺号直至任务结束”的回归。
- 置信度：高。服务端是否实际产生此异常序列未验证。

## 已检查且未发现问题的方面

- **服务地址边界**：官方来源限制域名、协议和端口；拒绝 URL 用户信息、查询参数及 fragment。自定义 HTTP 仅允许明确的回环地址。生产 session 均拒绝重定向。
- **凭据隔离与落盘方式**：不同服务不借用彼此 Key；shell 文件仅解析字面量，不执行。临时凭据文件以 `0600` 创建，最终文件恢复 `0600`。不使用钥匙串是文档明确记录的设计，未计为缺陷。
- **日志与错误展示**：正常路径不记录 Key、请求正文或响应正文；远端错误消息仅用于本地分类。润色模型名有日志过滤。
- **超时与取消**：ASR 区分启动、上传和最终结果期限，累计音频有上限；主调用链另设润色 10 秒硬截止及一次性结果选择，迟到响应不会再次输入。
- **响应与提示注入边界**：润色拒绝截断结果、工具调用及内联思考内容；终端结果拒绝换行和控制字符，最终输入还有清洗。模型没有工具执行入口。语义忠实性仍依赖模型，文档已说明命令执行前需人工核对，未将这一已知边界计为缺陷。

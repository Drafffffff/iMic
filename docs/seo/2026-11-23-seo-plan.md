## 结论

1. **主切入点：Mac mini、Mac Studio、Mac Pro 没有内置麦克风。** 这类用户想用语音输入时，系统听写根本没有声音来源，必须外接麦克风，或者用 Continuity Camera 把 iPhone 当麦克风，后者限制很多。VoxChord 正好解决这个问题：拿起已经在手边的 iPhone，按住就说，文字落进 Mac 光标处，不用买麦克风。这是搜索意图最明确、和产品最贴合的一类关键词。
2. **官网现在几乎没有可被搜索命中的词。** 标题、描述和 H1 都是口号。中文页「语音输入 / 语音转文字 / 听写 / 麦克风」出现 0 次，英文页「voice typing / dictation / speech to text / microphone」也是 0 次。另外没有 sitemap，也没有结构化数据。这些都是一两天就能补上的硬伤，收益最大。
3. **执行顺序**：先做技术 SEO 和关键词改写，再上线一个中英文的 **Mac mini 专题页**，然后调整 App Store 关键词和推广文本，最后做站外首发和长尾内容。

## 2. 目标用户与关键词

按搜索意图分为四组，优先级从高到低：

### A. Mac mini / Studio / Pro 没有麦克风（主攻）

- 中文：Mac mini 麦克风、Mac mini 没有麦克风、Mac mini 语音输入、Mac mini 听写、Mac Studio 麦克风、iPhone 当 Mac 麦克风、手机当电脑麦克风
- 英文：mac mini microphone、mac mini no microphone、mac mini dictation、mac studio microphone、use iPhone as microphone for Mac、iPhone as mic for Mac mini

事实依据：Apple 的 Mac mini 使用手册写明，需要音频输入的功能要外接麦克风或耳机。Continuity Camera 可以把 iPhone 当麦克风，但要求同一 Apple 账户并开启双重认证、10 米内开着 Wi‑Fi 和蓝牙、iPhone **横放、静止且熄屏**，同一时间只能接一台 Mac，也不能同时使用 iPhone 镜像等其他连续互通功能（[Apple 支持](https://support.apple.com/en-us/102546)）。

VoxChord 在这个场景的差异点（专题页要写清楚）：

| | USB 麦克风 | Continuity Camera | VoxChord |
|---|---|---|---|
| 额外硬件 | 要买 | 不用 | 不用 |
| 手机用法 | — | 必须横放、静止、熄屏 | 拿在手里，按住说话 |
| 文字输入 | 还要另配听写 | 还要另配听写 | 直接落进 Mac 光标处，可下拉发送回车 |
| 多台 Mac | 插拔 | 一次一台，同一 Apple 账户 | 配对多台，一点切换 |
| 识别与润色 | 取决于听写工具 | 系统听写 | 百炼识别 + 可选 AI 润色 |
| 适合 | 录音、会议、播客 | 视频会议 | 打字、给 Agent 下指令 |

要诚实写出「录音、视频会议请用 USB 麦克风或 Continuity Camera，VoxChord 不是系统音频输入设备」，这一点既是信任，也能避免错误流量。

### B. Mac 语音输入 / 语音打字（核心品类）

- 中文：Mac 语音输入、Mac 语音转文字、Mac 听写、Mac 语音打字、语音输入法 Mac
- 英文：voice typing Mac、dictation app for Mac、speech to text Mac、Mac dictation alternative

### C. 给 AI Agent / 终端 / 编辑器语音下指令（差异化长尾）

- 中文：语音写 prompt、语音给 Agent 下指令、终端语音输入
- 英文：voice prompt for coding agents、dictate in terminal、voice input for Cursor / Claude Code
- 网站内容中可以描述性提到具体工具；App Store 关键词里不要放其他公司的商标（审核指南 2.3.7，见 `docs/appstore/listing.md`）。

### D. 竞品与替代（后期）

- Continuity Camera microphone not working、Mac 听写不准、MightyMouse / MicCarry alternative
- 已有竞品在做同样的内容：[MicCarry](https://www.miccarry.com/blog/mac-mini-studio-no-microphone) 以「Mac mini 没有麦克风」为 H1；[MightyMouse](https://getmightymouse.com/blog/use-iphone-as-microphone-for-mac/) 有「iPhone 当 Mac 麦克风」长文，也是按住说话、在 Mac 光标处打字。说明这个需求真实存在，而且需要尽快占位。

### 中文市场注意

iPhone 版不在中国大陆 App Store 上架，`github.io` 在中国大陆访问也不稳定。中文 SEO 先面向 Google，覆盖港澳台、海外华人和能访问 Google 的用户；中文页面上已注明「中国大陆商店暂未上架」。后续可以考虑繁体中文（zh-Hant）本地化官网和 App Store 页面。

## 3. 技术 SEO（P0，随 1.5.0 一起上线）

1. **title / description 改写**（保留口号，补关键词）
   - 中文 title：`VoxChord：用 iPhone 给 Mac 语音输入 · Mac mini 也能用`
   - 中文 description：`按住 iPhone 说话，文字直接落进 Mac 光标处。Mac mini、Mac Studio 没有麦克风也能语音输入，支持 AI 润色、多台 Mac 切换，给 Agent 下指令。`
   - 英文 title：`VoxChord: Voice Typing for Mac with Your iPhone`
   - 英文 description：`Hold your iPhone, speak, and the words land at your Mac's cursor. Dictation for Mac mini and Mac Studio without a microphone, with AI polish and multi-Mac switching.`
   - 两者都要控制在搜索结果可显示的长度内（title 约 60 个英文字符或 30 个汉字）。
2. **首屏副标题**：H1 口号下面加一句带关键词的说明，例如「用 iPhone 给 Mac 语音输入：按住说话，文字直接落进光标处。」
3. **sitemap.xml**：列出首页、更新日志、Mac mini 专题页的中英文 URL，带 `xhtml:link` hreflang；robots.txt 加 `Sitemap:` 行。用 `tools/` 下的脚本生成，`check-site.py` 校验。
4. **JSON-LD**
   - `SoftwareApplication`（iOS）：名称、`operatingSystem: iOS 17`、`applicationCategory: ProductivityApplication`、`offers`（2.99 USD）、App Store 链接。
   - `SoftwareApplication`（macOS）：免费、macOS 13+、下载链接。
   - `FAQPage`：取首页 FAQ 和专题页 FAQ 的问答。
   - `Organization` / `WebSite`：品牌名，`sameAs` 指向 GitHub 和 App Store。
5. **站长平台**：Google Search Console、Bing Webmaster Tools 验证并提交 sitemap（需要你本人用自己的 Google / Microsoft 账号操作；验证用的 meta 标签或文件我可以加）。
6. **图片与视频**：现有图片 alt 已校验；给演示视频加一段文字说明，让搜索引擎能读到视频内容。

## 4. 内容：Mac mini 专题页（P0）

- 网址：`/mac-mini/` 与 `/en/mac-mini/`
- H1：`Mac mini 没有麦克风？用 iPhone 语音输入` / `No microphone on your Mac mini? Type with your voice from your iPhone`
- 结构
  1. 一句话回答：Mac mini、Mac Studio、Mac Pro 没有内置麦克风，系统听写需要外接音频输入（引用 Apple 文档）。
  2. 三种方案对比（上面的表格），诚实写出各自适合的场景。
  3. 用 VoxChord 三步上手（Mac 下载 → App Store 安装 → 配对码），配真实截图或首页视频。
  4. FAQ：需要什么网络？要不要同一 Apple 账户（不需要）？能不能当会议麦克风（不能）？延迟多少？隐私如何？能连几台 Mac？
  5. 底部下载卡片，复用首页样式。
- 首页 FAQ 增加一条「Mac mini / Mac Studio 没有麦克风能用吗？」并链到专题页；首页页脚和更新日志页也加入口，形成内链。

## 7. 域名（P2，越早决定越好）

`github.io/iMic` 的子路径和旧名对品牌搜索不利。建议购买独立域名（例如 voxchord.app，是否可注册需要你查），在 GitHub Pages 中设置自定义域名后，GitHub 会把 `drafffffff.github.io/iMic/` 自动重定向过去，已有的链接不会失效。但 Mac 客户端里写死了 appcast 地址 `https://drafffffff.github.io/iMic/appcast.xml`，换域名前要确认重定向后 Sparkle 仍能拿到更新，或者先发一个改用新地址的版本，过渡期两边都能访问。

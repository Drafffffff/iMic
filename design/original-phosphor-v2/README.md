# 原 UI · 辉光与轻 CRT 材质试验 V.02

根据用户本轮反馈，回到原版 iOS 的界面语言：iMic 像素字标、英文像素状态、黑橙配色、刻度弦、切角录音条与像素图标。保持主布局辨识度，只微调波形、说明文字及主操作之间的间距和字阶。

这里仍是独立代码预览，未连接麦克风、真实设备或识别服务。此方向已另外接入原生 iOS，见 [原生接入记录](../../docs/design/2026-10-27-native-phosphor.md)。按最新反馈，预览也移除了手势说明区（含张力数值）和录音条下方的常驻说明。`original.png` 是此前同一代码预览的无效果基线，不是原生应用截图。

## 运行

```sh
python3 -m http.server 8745 --bind 127.0.0.1 --directory design/original-phosphor-v2
```

打开 <http://127.0.0.1:8745/>。桌面右侧、窄屏下方的调校区可切换：

- 原始：关闭 bloom 与 CRT，保留同一布局与模型。
- 辉光：清晰线芯叠加近、远两层同色光晕。
- 辉光 + CRT：增加弱扫描纹、低强度 RGB mask、边缘亮度衰减与静态颗粒。

对照截图使用 `?material=original&still=1` 与 `?material=crt&still=1`，冻结同一环境相位，避免模型形态差异影响判断。系统状态栏区域不叠加屏幕纹理。

## 保留的交互

沿用 V.01 原型的固定端弦、跟手形变、弹簧回弹首次过中线时的整批弹射、高初速扇形轨迹与阻力，不改动这段用户认为可保留的释放反馈。正常操作的相机调得更接近原版环列轮廓；主体仍使用 xyz 几何与深度缓冲。

原型仍使用合成频谱与 DOM 字形；原生完整动效、CoreText 字形快门、触感、协议和实际输入逻辑尚未迁移。图形采用 WebGL 2 shader，控件的发光与显示纹理由 CSS 合成，未导入 RetroArch shader。后续原生实现可在此材质方向确认后再评估统一 Metal 后处理。

## 资源与验证

- `wordmark.png` 直接复用原生 `Wordmark.imageset/wordmark@3x.png`；像素图标沿用原版字模。
- `pixel.ttf` 沿用 V.01，从本项目原生 5×7 字模生成。
- 三档材质开关、录音模拟、释放演示已在浏览器检查；释放后 `sent=true`，飞行字形数回到 0。
- JavaScript 语法检查与 `git diff --check` 通过，浏览器没有页面异常。
- 未修改原生文件，因此没有重复构建原生应用。

# 恶魔低语 · 荧光线框 V.01

独立的代码视觉与交互原型。主界面、设置页与三维声场都由代码绘制，没有使用生图模型。未修改或接入 iOS / Mac 运行代码；未访问麦克风、网络链路、识别服务或真实设备配置。

## 预览

在仓库根目录运行：

```sh
python3 -m http.server 8744 --bind 127.0.0.1 --directory design/phosphor-v1
```

打开 <http://127.0.0.1:8744/>。无需安装依赖，需要 WebGL 2。桌面右侧提供材质开关、视角与演示按钮；手机尺寸下这些调校项位于界面下方。

## 这一版可以评审什么

- 黑底、蓝色声场、橙色动作、少量绿色确认，以及细线音频仪器控件的组合。
- 主界面「设备—状态—三维主体—手势说明—主操作」的层级，及设置页的直接配置结构。
- 44 个真实 xyz 圆环截面、纵向连接线、相机投影与深度缓冲。侧视可验证三维结构。
- 线芯渲染、半分辨率双尺度 Gaussian bloom 与最终合成。关闭辉光后几何不变；扫描纹与静态颗粒可单独关闭。
- 按住录音按钮模拟识别，或点击「开始录音演示」持续模拟；文字飞入并附着于同一三维几何的投影位置。
- 下拉声场后松手：弹簧回弹首次经过中线时整批释放文字，高初速扇形轨迹与空气阻力形成短促爆发。上拉可清空演示文字。
- 设置选项在本地切换，保持固定布局。Esc 关闭浮层；声场可用下箭头蓄力、Enter 释放。
- 环境动效保留 40 秒，随后 4 秒收住并停止请求帧；后台暂停，交互恢复。浏览器的「减少动态效果」设置下省略环境运动及明显文字飞行。

## 当前边界

这是确认画面和关键运动方向的原型，不代表原生完整动效已迁移。频谱为合成信号；文字采用 DOM 字形与三维锚点投影，尚未接入现有 CoreText atlas、字形快门采样、接触亮弧/火花、完整上拉删除形变、光标操作及原生触感。示例最多绘制 64 个字，完整演示文本仍保留在结果栏。后续按 [原生迁移评估](../../docs/design/2026-10-27-waveform-3d-plan.md) 的验收矩阵逐项保留。

当前 WebGL 后处理为本项目原型编写，参考通用的线芯、光晕与复古显示分层方法。没有复制或导入 RetroArch shader，也没有声称完成 Slang → Metal 移植。已核实的候选及来源见 [方向评估](../../docs/design/2026-10-27-ui-direction.md)。原生方案拟使用 SwiftUI 控件与统一 Metal 场景，需在真机测量 GPU 成本和清晰度。

`pixel.ttf` 从本项目 `ios/iMic/PixelFont.swift` 的 5×7 字模生成，用于短英文技术标签。正文使用系统中文字体。
